# HurshNote 需求

> 本文件第一部分是原始需求（保持原文），第二部分是规划阶段确认的澄清与取舍。
> 二者冲突时，以第二部分为准。

---

## 第一部分：原始需求

### 1. 核心编辑体验（Core Editing）

* **主题：** Gruvbox Light。
* **Ctrl + 滚轮缩放：** 动态无级调整文本与字体点阵大小。
* **列选模式（Column Mode）：** 支持 `Alt + 鼠标左键拖拽` 进行矩形多行垂直光标选取与批量插入。
* **智能列表补全：** 检测以 `1. ` 或 `- ` 等开头的行，按 `Enter` 换行时自动生成后续编号（如 `2. `）或项目符号，双击回车自动取消。
* **多光标编辑（Multi-Caret）：** 支持 `Ctrl + 鼠标左键` 在文本多处同时放置光标并同步编辑。
* **语法高亮与代码折叠：** 支持主流代码与配置文件（JSON、XML、Python、C/C++、SQL、YAML、Markdown 等）语法着色与层级折叠。
* **行号与缩进参考线：** 提供行号栏、可视代码对齐缩进指示线、括号自动匹配与成对高亮。
* **加密：** 支持文件保存为加密文本（Only-App Encrypted Files）。

### 2. 多模式与视图扩展（Multi-Mode Views）

* **Markdown 实时预览：** 基于轻量解析引擎（MD4C），支持原生内嵌/分栏渲染，毫秒级解析且无常驻浏览器进程开销。
* **十六进制视图（Hex View）：** 支持纯文本与 Hex 视图一键无缝切换，基于内存映射（mmap）与固定 16 字节网格虚拟滚动，GB 级二进制镜像文件秒开。
* **双视图分屏对比（Split / Clone View）：** 支持左右或上下分屏，允许多个视口共享同一份内存缓冲区，修改实时双向同步。
* **只读锁定模式（Read-Only Toggle）：** 一键锁死编辑状态，防止排查配置或阅读海量日志时意外误触修改。

### 3. 开发者工具与数据清洗（Developer & Data Tools）

* **嵌入式伪终端（ConPTY）：** 底部抽屉式一键呼出交互式原生 PowerShell / CMD，支持 ANSI 全彩显示与命令自动补全。
* **一键运行 Python 程序：** 独立后台进程与匿名管道捕获，实时将 STDOUT / STDERR 日志流回显至输出面板，不阻塞界面。
* **换行符识别与转换（CRLF / LF）：** 状态栏实时显示当前行尾格式，支持一键批量双向转换，并提供空格/制表符/换行符可视化显隐开关。
* **编码格式识别与切换：** 自动嗅探文件编码（BOM 头与 uchardet 统计推断），支持 UTF-8、UTF-16、GBK/GB18030 等格式互转。
* **目录级全局正则搜索（Find in Files）：** 后台多线程递归扫描指定目录内文件，正则匹配并集中在底部列表呈现，点击直达文件对应行。
* **书签标记与批量提取：** 支持行号栏点击或 `Ctrl + F2` 打书签，提供"复制所有带书签行"、"删除所有带书签行"等过滤操作。
* **高频行操作（Line Operations）：** 支持选中行快速升序/降序排列、全局去重（Unique）、一键清除行尾空白字符（Trim）、合并行以及 `Ctrl + Shift + Up/Down` 快速挪动单行。

### 4. 侧边栏与界面交互（Sidebar & UI Shell）

* **侧边栏文件树与工作区：** 替代顶部标签页设计，垂直呈现当前已打开文件与工作区目录树。
* **原生文件类型图标呈现：** 直接调用系统 Shell 提取已安装程序的官方关联图标，界面风格与 Windows 完全统一且零安装包体积开销。
* **状态栏全状态实时指示：** 实时展示光标行列号、已选中字符数/行数、当前编码格式、EOL 换行符类型、文件修改 Dirty 状态。

### 5. 底层引擎与容灾机制（Engine & Reliability）

* **无感快照自动缓存（Session Snapshot）：** 仿照 Notepad++ 机制，编辑变动后防抖异步暂存快照到本地，无需手动保存即可关闭程序，重启后完全恢复编辑现场与未保存状态。
* **内存映射大文件秒开（Memory-Mapped I/O）：** 采用虚拟内存映射，打开 GB 级大文本或日志文件零等待，按视口需缺页调度。
* **外部文件变更监控（File Change Monitor）：** 自动监听文件被外部修改，弹出重载提醒；对日志支持追加滚动模式（Tail 监控）。

## 第二部分：澄清与取舍（规划阶段已确认）

| # | 原始描述 | 确认后的做法 | 原因 |
|---|---|---|---|
| C1 | 内存映射秒开 GB 级文件 | **双层模式**：小于阈值（默认 256 MB，可配置）走完整编辑器；超过阈值走"大文件视图"，v1 为**只读 + 搜索 + 跳转 + Hex + Tail** | 语法高亮、多光标、撤销都需要可修改的全量缓冲区，和 mmap 零拷贝不能放进同一个引擎；可编辑的分块引擎工期约翻倍，放到 v1 之后 |
| C2 | Tail 监控基于 mmap | Tail 模式用普通 `ReadFile` 读文件尾部，**不用 mmap** | Windows 上映射未关闭时，写日志的进程无法截断或轮转文件；文件被外部缩短后访问映射页会触发 `EXCEPTION_IN_PAGE_ERROR` |
| C3 | Markdown 预览基于 MD4C | 解析用 `pulldown-cmark`（与 MD4C 同类的 CommonMark/GFM 解析器，纯 Rust）；**原生 Direct2D/DirectWrite 自绘**分栏预览；不启动任何浏览器内核 | 满足"无浏览器进程"；代价：不支持内嵌 HTML、数学公式；不做 Typora 式所见即所得 |
| C4 | 加密文件 | **密码派生**：Argon2id + AES-256-GCM。换电脑可打开；**忘记密码无法恢复** | 用户确认 |
| C5 | 加密 vs 快照 | 加密文件的快照用同一密钥、同一格式加密后再落盘；恢复时需要重新输入密码；崩溃转储不含堆内存 | 否则明文会泄漏到 `%APPDATA%` |
| C6 | 侧边栏替代标签页 | 额外提供 **Ctrl+Tab 最近使用顺序切换** 和 **Ctrl+P 快速打开** | 没有标签页时切换文件的效率不能倒退 |
| C7 | uchardet | 改用 `chardetng`（Firefox 同款）+ BOM + UTF-16 无 BOM 启发式；允许手动覆盖并按文件记住 | 对 GBK/UTF-8 混淆的判断更好，纯 Rust |
| C8 | 运行环境 | **最低 Windows 10 1809 x64**，不支持 ARM64、Win7/8 | 用户确认；1809 是 ConPTY 首个可用版本 |
| C9 | 分发 | 便携 zip + Inno Setup 安装包，**不做代码签名** | 用户确认；接受首次运行时 SmartScreen 提示；因此不做 Win11 新版右键菜单（需要签名的稀疏包），只注册经典右键菜单 |
| C10 | 开源协议 | **MIT** | 第三方组件（Scintilla/Lexilla、ripgrep 组件、alacritty_terminal、RustCrypto 等）均为宽松协议；**不得复制 Notepad++ 代码（GPL）** |

### 隐含需求（Notepad++ 老用户默认存在的功能，必须覆盖）

- 查找/替换：普通、转义（`\n` `\t`）、正则三种模式；全部替换；计数；标记全部；仅在选区内；循环查找
- 宏录制与回放
- 打印
- 拖放打开文件/文件夹
- 最近打开的文件列表
- 命令行参数：`hurshnote file.txt -n120 -c5`（跳到指定行列）、`-ro`（只读）、`-multiInst`
- 单实例：第二次启动时把参数转给已有窗口
- 打开超长单行（压缩 JSON）不卡死
- 保存到受保护路径（hosts、Program Files）时提权
